# 墨迹 · 手写模拟器

一个在浏览器中运行的中文手写效果工具。输入段落后可调整字体骨架、笔画质感和排版，并复制普通文字或裁切后的透明字迹 PNG。

## 功能

- **普通手写**：调整字形、墨色、字距、行距、潦草幅度等参数。
- **样本仿写（实验）**：上传一张手写段落照片，在浏览器本地识别原文，并估计笔画粗细、墨色、字幅和行距，再把这些特征应用于新的文字。
- **输出**：「复制文字」得到可编辑的普通文本；「复制字迹」得到紧贴文字的透明 PNG；「导出字迹」保存高分辨率透明 PNG。

> 样本模式目前是**笔迹特征模拟**。新字由预置字体提供结构，并非从少量样本训练出的个人字体；偏旁写法、笔顺和连笔未必与本人一致。OCR 可能识别错字，照片原文仅辅助估计字距，不作为逐字裁剪的依据。

## 在线体验

启用 GitHub Pages 后，从仓库的 Pages 链接打开。首次识别照片需要下载本仓库托管的 OCR 模型，可能要等待一会儿；进度栏会显示处理状态。

## 本地运行

在仓库根目录启动任意静态 HTTP 服务，例如：

```sh
python -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/`。照片在浏览器内处理，应用不会将照片上传到服务器。直接用 `file://` 打开网页时，自动 OCR 不可用。

## 仓库内容

`index.html` 和 `personal.js` 是页面与样本模式源码。`ocr-entry.js` 是 OCR 入口源码，`ocr.js` 是由官方 PaddleOCR.js SDK 打包的浏览器脚本。`ocr-assets/` 包含本地推理所需的模型及 ONNX Runtime Web 文件。`fonts/` 是所用的 OFL 字体。用户手写照片、实验缓存和模型测试样本均未收入仓库。
